# data/

Input datasets for the thesis: HTTP trace archives (ClarkNet, Calgary), processed RPS time series, generated trace-replay artifacts, and the deployed GRU model. Not experiment outputs; those live in `../results/`.

## Module map

| Path | Responsibility |
|---|---|
| `raw/` | Original HTTP log archives (`clarknet/`, `calgary/`, plus `*_actual/` copies). Gitignored (`raw/**/*.gz`); fetched with `scripts/download_datasets.sh` |
| `processed/` | Canonical training inputs: RPS parquet (`clarknet_real_rps.parquet`, `calgary_real_rps.parquet`), train/val/test splits, model artifacts (`*.joblib`), model-comparison CSVs. Parquet and joblib are gitignored (`data/.gitignore`) |
| `trace-replay/` | Generated k6 artifacts: `*_k6_stages.json`, replay manifests, and `synthetic_archetypes.py` (archetype generator: spike, ramp, periodic, stationary). Regenerated by `thesis experiment trace-replay`; never hand-edited |
| `scripts/` | Dataset preparation only: `clf_parser.py` (CLF log to RPS parser, standalone with argparse `main`), `download_datasets.sh` |
| `models/` | Deployed GRU artifact: `gru_model.pt` + `gru_model.json` (plus `synthetic-bak.*` backup). Read by `apps/prediction` (`model_loader.py`, `server.py`) and `apps/experiment` (`services.py`); replaced only via the study promote path |

## Module direction

- **May import:** nothing imports `data/` at runtime. Apps consume these artifacts by path (e.g. `data/processed/clarknet_real_rps.parquet`, `data/trace-replay/clarknet_replay_manifest.json`). `data/scripts` is importable (`from data.scripts import clf_to_rps`) but has no live importer; it is a standalone prep CLI.
- **Must never import:** n/a (no package code depends on apps or libs; keep it that way).
- **Where new code goes:**
  - A new dataset preparation step: `scripts/`.
  - A new generated artifact tree: the generator lives in the owning app (trace-replay generation is `apps/experiment/experiment/trace_replay.py`, exposed as `uv run thesis experiment trace-replay`), artifacts land under `data/<tree>/`.
  - A new deployed model artifact: `models/`, promoted by the owning study (`apps/experiment/experiment/tuning/gru_study.py --promote`), never copied by hand.

## Tests

No tests under `data/`. The CLF parser's original suite is archived (`archived/experiments-framework/tests/test_clf_parser.py`); live coverage is none, so parser changes are verified by running the CLI on a sample log. Trace-replay generation is exercised through the experiment app's suites.

## Commands it contributes

None. The command that generates `trace-replay/` is `uv run thesis experiment trace-replay` (owned by `apps/experiment`); dataset download is `bash data/scripts/download_datasets.sh`; CLF parsing is `python data/scripts/clf_parser.py` (argparse entry point).

## Invariants

- Raw data is never committed: `data/.gitignore` ignores `raw/**/*.gz`. Fetch with `scripts/download_datasets.sh`.
- `processed/` parquet and joblib are gitignored; they are regenerated by the parser pipeline, not versioned. Note that `data/` has no Git LFS entries: the root `.gitattributes` covers only `docs/references/*.pdf` and `results/experiments/**/*.parquet`.
- `processed/` parquet is the canonical training input. `apps/experiment/experiment/trace_replay.py` reads it (`DATA_DIR = data/processed`) and writes stages JSON to `data/trace-replay/` plus k6 scripts to the app's `load_tests/canonical/`. The former `scripts/generate_trace_replay.py` no longer exists; that module is its port.
- `trace-replay/clarknet_replay_manifest.json` records the replay window and scale factor; the GRU study reads it to align training and serving amplitude. Treat it as the source of truth for what the testbed replays.
- `models/gru_model.pt` is the deployed prediction artifact. It is backed up and replaced only by `gru_study --promote`; probe artifacts are deliberately written elsewhere.
- Archetype stages (`archetype_*_k6_stages.json`) are out-of-distribution checks, never used for model selection.
