# Citation check: Introduction + Method (CiteIntroMethod)

Scope: sentences in `paper/sections/body.typ` and `paper/sections/common.typ` that cite the 13 assigned keys, plus the three ElaX descriptions. Page numbers are PDF page numbers of the archived file, except where "printed" is given. No `journal-only` text cites an assigned key; `body.typ` 150-157 (extended) describes the decision factor without a citation and makes no ElaX claim.

Source-access notes:
- `golec2023cold`, `cawley2010overfitting`, `optuna2019`, `k8sca-faq`, ClarkNet: no archived file; read full text from arXiv, jmlr.org, GitHub raw, ita.ee.lbl.gov.
- ElaX: `pdftotext -raw` on the PDF (the md copy truncates lines).
- "Decision factor": the string does not occur in the ElaX PDF. ElaX's resource model is `R = σ · y + β` (Eq. 3, PDF p.5, σ = sigma, y = workload), not `α x + β`.
